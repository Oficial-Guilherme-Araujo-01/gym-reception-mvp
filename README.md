# 🏋️ MVP - Sistema de Controle de Recepção de Academia

Sistema desenvolvido em Python com **Flask** e **SQLite** para gerenciar o cadastro de alunos e o registro de check-ins na recepção de uma academia.

## 🚀 Tecnologias Utilizadas
* **Python 3.x**
* **Flask**
* **SQLite**
* **Pytest**

## ⚙️ Como Executar Localmente
1. Clone o repositório e entre na pasta do projeto.
2. Crie e ative o ambiente virtual: `python -m venv venv` e `source venv/Scripts/activate`.
3. Instale as dependências: `pip install -r requirements.txt`.
4. Execute a aplicação: `python app.py`.
5. Para rodar os testes: `PYTHONPATH=. pytest`.
